# Graph Data Structure and Dijkstra's Shortest Path Algorithm

This workspace contains a small Python demo and supporting documentation for a self-study report on graphs and Dijkstra's algorithm.

The script now prints an ASCII graph sketch first, then the shortest paths.

## Files

- `code.py` — runnable Python demo
- `sample_graph.json` — example JSON graph for custom runs
- `Rename.md` — improved report
- `User_Guide.md` — how to run the code

## Quick Start

```powershell
cd "D:\save cjy"
python .\code.py
```

To try a custom graph example:

```powershell
python .\code.py --graph-file .\sample_graph.json --start A
```
